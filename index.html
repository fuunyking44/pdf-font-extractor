Extract the fonts embedded in a PDF

Drop a PDF and get every embedded font back as a TTF, OTF or CFF file. Parsing happens in your browser — the document is never uploaded.

How it works

A PDF does not store text as text. It stores instructions to draw glyphs, and those glyphs come from a font program that is usually copied into the file — that copy is what makes a PDF look the same on every machine. The two places it can live are named FontFile2 (TrueType) and FontFile3 (OpenType or CFF), and each one is a compressed stream somewhere in the file.

This tool reads the whole file, finds every stream object, decompresses the ones that are deflated, and keeps whatever begins with a font signature — 00 01 00 00 for TrueType, OTTO for OpenType, ttcf for a collection. Then it looks up the matching font descriptor to recover the real font name instead of a meaningless object number.

The subset problem, stated plainly. Almost every PDF embeds only the glyphs that appear on its pages. If your document uses 12 letters of a typeface, the extracted file contains those 12 letters and nothing else. This is not a limitation of this tool — the other characters were thrown away when the PDF was created, and no tool can recover them. A PDF written without subsetting is rare but does exist, and those extract cleanly.

Questions people actually ask

How do I extract a font from a PDF?

Drop the PDF on the box above. The tool lists every embedded font with its name, its format and its size. Press download next to a font to save it, or “Download all” to get every one. There is no step two.

Why are some fonts missing from the results?

Because the PDF never embedded them. Documents that use Helvetica, Times or Courier usually embed nothing at all, since every reader already ships those. If the list is empty, the file genuinely has no font programs inside it.

Why does the extracted font only contain a few characters?

Subsetting. See the note above — most PDF writers keep only the glyphs on the page to save space. The missing characters are not hidden in the file; they are absent.

Is my PDF uploaded anywhere?

No. The file is read with the browser's FileReader API and parsed in JavaScript in this tab. Nothing is sent, logged or stored. You can disconnect from the internet after the page loads and it will still work.

What is a .cff file and can I install it?

A bare CFF stream has no font container around it, so Windows and macOS will not install it by double-clicking. Open it in FontForge and export as OTF, or drop it into a web font pipeline that accepts raw CFF.

Am I allowed to reuse a font I extracted?

A font file carries its own licence, and being able to extract it does not grant you the right to use it. Many commercial fonts are licensed for document embedding only. Check the foundry's terms before shipping an extracted font in your own work.
